## Technology Stack

- **Frontend:** React 19, Vite, Tailwind CSS v4, Lucide Icons
- **Backend:** Next.js 16 (API Routes / Route Handlers)
- **Database:** MongoDB with Mongoose
- **Authentication:** JWT, bcrypt password hashing, and role-based access control (Citizen, Officer, Admin)

## How to Run

### 1. Start the Backend (Port 5000)

```bash
cd backend
npm install
npm run dev
```

### 2. Start the Frontend (Port 8080)

Open a second terminal:

```bash
cd frontend
npm install
npm run dev
```

Open http://localhost:8080 in your browser.
